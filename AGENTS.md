# MaskFill — Project Principles

- **100% FREE and UNLIMITED** — never introduce paywalls, trials, premium tiers,
  feature limits, or paid quota. Everything ships free.
- **PRIVACY-FOCUSED** — zero network requests, no analytics, no tracking, no
  remote code. All user data lives in `chrome.storage.local` only (never synced,
  never sent anywhere).
- Guard every feature by these rules: no new permissions beyond what is strictly
  needed, no hidden data collection, no third-party APIs.
